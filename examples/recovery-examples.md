# SafeRestore recovery examples

## Overview

These fictional scenarios illustrate how a writer can explain user goals without making unsupported product promises.

## Before you begin

Use the [SafeRestore user guide](../docs/user-guide.md) for the general workflow.

## Procedure

### Example: Recover one file

An administrator selects a recovery point from before the file was changed, selects the file, and chooses a writable destination.

### Example: Recover a folder

An administrator browses to the folder in a suitable recovery point, selects the folder, and checks the destination before starting the job.

## Troubleshooting

These scenarios are examples, not product guarantees. Confirm available options and behavior against the actual product.
