# SafeRestore troubleshooting

## Overview

Use these checks to resolve common recovery workflow issues in the fictional SafeRestore product.

## Before you begin

Have the source name, recovery point date, and job status available. Confirm that your account has Restore permission.

## Procedure

1. Open the activity panel and select the recovery job.
2. Read the displayed status and message.
3. Apply the matching action below, then retry the recovery if appropriate.

## Troubleshooting

| Symptom | What to check | Action |
| --- | --- | --- |
| Source is not listed | Account permissions and source availability | Ask an administrator to confirm access. |
| File is missing | Selected recovery point date | Choose a point from when the file existed. |
| Recovery is queued | Current system activity | Wait for the job status to update. |
| Destination error | Free space and write access | Select a writable destination with sufficient space. |

For the full workflow, see [Recover files with SafeRestore](user-guide.md).
