# Recover files with SafeRestore

## Overview

SafeRestore lets an administrator recover selected files from a protected backup. This guide describes a fictional product and is provided as a documentation sample.

## Before you begin

- Sign in with an account that has the **Restore** permission.
- Confirm that a recovery point includes the files you need.
- Choose a destination with enough free space.

## Procedure

1. In the SafeRestore console, open **Protected data** and select a source.
2. Select **Recover**.
3. Choose a recovery point and browse to the required files.
4. Select a destination, then choose **Start recovery**.
5. Review the activity panel for the job status.

For common issues, see [Troubleshooting](troubleshooting.md). Review [recovery examples](../examples/recovery-examples.md) for sample scenarios.

## Troubleshooting

If a file is not listed, select a recovery point from a date when the file existed. If the destination is unavailable, choose another destination and verify access permissions. See the full [troubleshooting guide](troubleshooting.md).
